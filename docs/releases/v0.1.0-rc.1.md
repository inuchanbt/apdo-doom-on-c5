# APDO DOOM on C5 0.1.0-rc.1 — native v9.1

Native DOOM/Freedoom E1M1 on the **WITRN C5**, with standalone play and optional
browser PC controls. This is an **owner-tested Pre-release**, not a stable release.

The owner installed the exact v9.1 package on one C5 and confirmed standalone
gameplay, PC keyboard input, JPEG preview/enlargement/save, physical 180° rotation
and brightness adjustment. Live HID status and actual 320×172 JPEGs were recorded;
about 90 seconds of status samples stayed connected with application error 0.

v9.1 corrects the Cortex-M4 FPU setting to `fpv4-sp-d16`, rejects unsupported M4
instructions at build time and displays PC/LR fault diagnostics. The firmware
is byte-identical to the candidate used for the owner's check.

## Download

- **`APDO-DOOM-C5-0.1.0-rc.1-install.zip`**: firmware, complete matching source,
  Windows setup/menu, PC controller, read-only backup/qualification/audit helpers,
  English/Japanese instructions, licenses and per-file checksums.
- `APDO-DOOM-C5-0.1.0-rc.1-source.zip`: corresponding source and notices.
- `SHA256SUMS.txt`: checksums for the two archives.

Extract the whole install ZIP. Read `README.md` / `README.ja.md` and the install
and recovery documents before running `setup.cmd`. The official WITRN updater,
stock firmware, Python/compiler and personal Flash backups are **not bundled**.
Setup installs pinned hidapi into a local virtual environment; Internet is
required for that dependency unless it is already cached.

Firmware: `firmware/build/C5-native-doom-v9.1.c4ser`, **917,504 bytes**.
SHA-256: `186bd3aea083dc85c3b7de2e115a6d6f1eb0d74c1c5a70ed11ed5e1ddbc127bb`.

## Scope and limits

Only the owner's C5 with the pinned 2024-08-06 bootloader is qualified. Use the
read-only helper to check **your own** bootloader and retain your own backups.
**Follow-up, 2026-11-17:** the owner restored stock **V8.5** on the same C5 and
tried its functions without observing problems. This is a functional restoration
report, not proof of byte-for-byte Flash preservation or calibration accuracy.
Other units/bootloaders, long-duration stability and a new post-install full-Flash
preservation audit remain unverified.
The downloadable archives and tag remain the original publication snapshots;
this follow-up updates the release notes and main-branch documentation.
The game replaces the stock measurement app. No commercial DOOM WAD is included.

After updating, close the official updater, disconnect **all power feeds**, then
connect the PC to the HID port without holding OK. During the check, an initial
failure to enumerate recovered after reconnection; the underlying cause was not
determined. Keep only one controller/monitor/updater open at a time.
