# 導入・起動 — 実機未確認のv9.1候補

[English](INSTALL.md) · [純正への復帰](RECOVERY.ja.md)

所有者の実機確認までバイナリ公開を保留しています。以下は準備した確認キット用の手順です。

1. ZIP全体を書き込み可能なフォルダーへ展開します。Windows用Python 3.11以降を用意し、
   `setup.cmd` を実行します。フォルダー内に `.venv` を作り、固定版の `hidapi` を導入します。
   初回セットアップにはインターネット接続が必要です。ローカル確認にはPython 3.14を使いました。
   PATHにPythonがない場合は、端末から `setup.cmd "C:\path\to\python.exe"` と指定できます。
2. `C5-Tools.cmd` の **1** で、同梱ファイルとチェックサムを確認します。USBにはアクセスしません。
   ソースを取得した場合は、先にファームをビルドしてください。
3. [WITRN公式ダウンロードページ](https://www.witrn.com/?p=90)のC4/C4L/C5用リンクから、
   公式更新ツールと自分の機種に適合する純正ファームを別途用意します。同梱していません。
   更新ツール・純正パッケージ・復帰手順を確保してから進めます。
4. 更新ツールや他のHIDツールを終了します。データ通信対応ケーブルでC5のHID端子をPCに接続し、
   接続時に **OK** を押します。本体に **DFU** が表示されたら離します。
5. `C5-Tools.cmd` の **4** を選び、`DFU` と入力します。情報取得後、1MiBのFlashを2回読み、
   一致と対象ブートローダーのハッシュを確認します。`backups` 一式を非公開の安全な場所にも保管してください。
   ブートローダー不一致なら中止します。読み取り成功は復旧手段の実証とは異なります。
6. ヘルパーを閉じ、公式更新ツールで `firmware/build/C5-native-doom-v9.1.c4ser` を書き込みます。
   純正計測アプリが置き換わります。このキットにはC5用の消去・書き込み・生Flash復元ツールを含めていません。
7. 更新ツールを閉じ、**OKを押さずに** 接続し直します。最初にバナー、ゲーム、本体ボタン、
   移動・発射・メニューを確認します。
8. PC操作は `C5-Tools.cmd` の **2** で開始します。`http://127.0.0.1:8768/` が開いたら、
   画面内でキーボード操作を有効にします。プレビューON/OFF、拡大・保存、本体の180度反転、
   明るさを確認してください。電源を切ると表示設定は初期値へ戻ります。
   Ctrl+CでPC操作だけが終了し、本体のゲームは継続します。

モニターはPC操作を止めてから **3** で開始します。ログは `captures/` に保存されます。
個体固有のバックアップやレポートを公開コミットに含めないでください。

## 導入後の保存領域監査（任意）

DFUに入り、メニュー4で別名のバックアップを取得してから実行します。

```powershell
.\.venv\Scripts\python.exe tools\verify_install.py --before backups\自分の純正バックアップ --after backups\自分のDOOMバックアップ
```

**同じ自分の個体**の、2回読み一致済みの導入前後ダンプを比較します。
パッケージは896KiB、想定消去範囲は `0x08004000..0x080E3FFF` です。
メーカー更新ツールのファイル長計算による末尾48バイトも監査します。
アプリ、起動マーカー、消去末尾、ブート・工場領域、範囲後方の保持を確認しますが、
スタック使用量・長時間安定性・純正復帰は証明しません。他人の全Flashダンプを復帰用に使わないでください。

## 問題が起きた場合

- HIDが見えない場合：端子・データケーブル・DFU／通常モード・他ツールとの競合を確認します。
- CPU FAULTの場合：CFSR／PC／LRを含む画面全体を撮影し、直前の操作を記録します。
  DFUへ戻して復帰します。他機種のファームは使わないでください。
- プレビューが遅い場合：プレビューOFFの本体動作とも比較します。
- 開発確認中は充電・PD関連機器を外してください。このアプリはゲームで、純正計測UIを提供しません。
