# 純正への復帰と確認範囲

[English](RECOVERY.md)

導入前に、自分の個体の2回読み一致済みバックアップと、対象C5に適合する公式純正パッケージを用意します。
読み取りバックアップは保存されたバイト列の証拠であり、全Flash復旧手段の実証ではありません。
このプロジェクトは、生Flashへの復元ライターを提供していません。

純正へ戻す場合はPCツールを終了し、切断後、OKを押しながら接続して純正DFU画面へ入ります。
公式WITRN更新ツールで、正しいC5用の公式パッケージを書き込みます。
終了後に更新ツールを閉じ、通常接続で起動を確認します。
C4/C4L用ファームや他人の全Flashダンプで代用しないでください。

2026年11月17日、v9.1のゲームとPC操作の確認後、所有者が同じC5を **純正V8.5へ戻し、
各種操作で問題がない** と報告しました。1台での機能上の復帰確認です。
全Flashのバイト一致、校正精度、純正の全機能を実証するものではなく、新たな全Flash保持監査は未確認です。
この移植は対象ブートローダー内の関数に依存します。ブートローダーの書き換えは導入手順に含めていません。

DFU画面自体が出なくなった場合は中止し、元バックアップと異常時の情報を保管してください。
ホスト側ツールは、分解を伴う復旧経路を実証するものではありません。

v9.1候補は以前の大容量DOOM版と同じ限定消去範囲を使います。
オフライン監査でブート・工場領域・後方Flashの保持をモデル化しますが、
実機の読み戻しや復帰成功の代わりにはなりません。
